# Dünyanın En Abartılı Rastgele Türkçe Mazeret Üreticisi

**Uyarı: Bu proje şaka değildir. Bu, insanlık tarihinin en ileri mazeret teknolojisidir.**

## Nedir Bu?

Bu repository, tamamen rastgele, abartılı ve mantıksız Türkçe mazeretler üreten, gerçekten çalışan bir Python script'idir. Trafik, kedi, kahve makinesi, zaman yolculuğu, varolşsal krizler... her şey için bir mazeretiniz var.

Neden geç kaldınız? Artık sorun değil. Bu kod sizi kurtarır.

## Nasıl Çalışır?

1. `python mazeret_uretici.py` çalıştırın.
2. Sistem düşünür (abartılı şekilde bekler).
3. Size bilimsel olarak kanıtlanmış bir mazeret verir.
4. Hayatınız kurtulur.

## Özellikler

- %100 çalışır (test edildi, bir kere).
- Sonsuz mazeret potansiyeli.
- Kediler, trafik ve kahve ile uyumlu.
- Yapay zeka destekli (aslında random.choice).
- Hiçbir işe yaramaz ama komiktir.

## Kurulum

```bash
git clone https://github.com/Tentivory/rastgele-turkce-mazeret-uretici.git
cd rastgele-turkce-mazeret-uretici
python mazeret_uretici.py
```
